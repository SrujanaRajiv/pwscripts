# pwscripts

Playwright automation scripts repository.

## Projects

### [ContactUs-Automation](./ContactUs-Automation)

End-to-end Playwright + TypeScript suite for the WebDriverUniversity **Contact Us** feature (Page Object Model, Chromium + Edge).

**Quick start**

```bash
cd ContactUs-Automation
npm install
npx playwright install chromium
npm run test:chromium
```
